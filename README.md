# ScrapOS — Premium Recycling & Scrap Management Template

قالب مدیریتی حرفه‌ای برای مراکز جمع‌آوری، خریدوفروش و فرآوری انواع ضایعات.

## شروع سریع
1. فایل ZIP را استخراج کنید.
2. فایل `index.html` را در مرورگر باز کنید.
3. برای توسعه بهتر، پروژه را با یک وب‌سرور محلی اجرا کنید:
   - `python -m http.server 8000`
   - سپس `http://localhost:8000` را باز کنید.

## امکانات نسخه نمایشی
- داشبورد مدیریتی با KPI و نمودارهای نمایشی
- ماژول‌های باسکول، انبار، بانک مواد، خرید، فروش، فرآوری، اشخاص، مالی، ناوگان، گزارش‌ها، کاربران و تنظیمات
- زبان فارسی RTL و سوییچ نمایشی انگلیسی LTR
- پوسته روشن و تاریک
- جست‌وجو و فیلتر جداول
- ثبت معامله آزمایشی و ذخیره آن در LocalStorage
- خروجی CSV
- رابط واکنش‌گرا برای دسکتاپ، تبلت و موبایل

## نکات مهم
- این نسخه یک **قالب HTML تعاملی با داده‌های نمونه** است، نه نرم‌افزار عملیاتی متصل به دیتابیس.
- اطلاعات و مبالغ نمونه هستند و برای استفاده تجاری باید با داده‌های واقعی جایگزین شوند.
- اتصال سخت‌افزاری باسکول، احراز هویت واقعی، مجوزهای نقش‌محور، حسابداری قانونی، چندسازمانی و API در مرحله توسعه بک‌اند پیاده‌سازی می‌شوند.
- فونت‌های Vazirmatn و Inter از Google Fonts بارگذاری می‌شوند؛ برای استفاده آفلاین، فایل فونت‌ها را در `assets/fonts` قرار دهید و CSS را به‌روزرسانی کنید.
- برای انتشار در مارکت، مجوز استفاده از فونت‌ها و هر وابستگی خارجی را بررسی و مستند کنید.

## ساختار
- `index.html` — پوسته اصلی برنامه
- `assets/css/app.css` — طراحی و واکنش‌گرایی
- `assets/js/app.js` — تعاملات و داده‌های نمونه
- `locales/` — فایل‌های ترجمه
- `documentation/` — مستندات توسعه

## پیشنهاد مسیر توسعه
1. تثبیت طراحی و کامل کردن صفحات جزئیات و فرم‌ها
2. افزودن صفحات مستقل و تست RTL/LTR
3. اتصال به Laravel API و PostgreSQL
4. پیاده‌سازی کاربران، شعب، مجوزها و Audit Log
5. اتصال باسکول و چاپگر قبض
6. تست امنیت، پایداری و آماده‌سازی نسخه تجاری
