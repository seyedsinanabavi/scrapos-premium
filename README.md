# ScrapOS — قالب مدیریت ضایعات (نسخه پریمیوم)

قالب مدیریتی حرفه‌ای برای مراکز جمع‌آوری، خرید و فروش و فرآوری انواع ضایعات.
این مخزن **رابط کاربری تعاملی** است؛ داده‌های آن نمونه هستند و هنوز به بک‌اند متصل نیستند.

## اجرا

ماژول‌های JavaScript به‌صورت ES Module بارگذاری می‌شوند و مرورگر آن‌ها را از `file://` قبول نمی‌کند.
برای اجرا از یک وب‌سرور محلی استفاده کنید:

```bash
# از ریشه پروژه
python -m http.server 8000
```

سپس آدرس `http://localhost:8000` را باز کنید.

    └── PRODUCT-STRUCTURE.md   ماژول‌ها، قواعد دامنه و معماری هدف

## امکانات نسخه نمایشی

- داشبورد با کارت‌های KPI، نمودار نمونه و جدول آخرین معاملات
- صفحات باسکول، انبار، بانک مواد، خرید، فروش، فرآوری، اشخاص، امور مالی، ناوگان، گزارش‌ها، کاربران و تنظیمات
- زبان فارسی (RTL) و انگلیسی (LTR)
- تم روشن و تاریک
- جست‌وجو و فیلتر جدول‌ها، و خروجی CSV
- ثبت معامله آزمایشی در مودال

## محدودیت‌های نسخه فعلی

- **داده‌ها نمونه هستند.** مبالغ و اشخاص ساختگی‌اند و باید با داده واقعی از API جایگزین شوند.
- **معاملات در `localStorage` ذخیره می‌شوند** (فقط برای نمایش). در نسخه عملیاتی باید به API منتقل شوند؛ محل این تغییر در `assets/js/data/transactions.js` علامت‌گذاری شده است.
- **اتصال سخت‌افزاری باسکول، احراز هویت، مجوزهای نقش‌محور و حسابداری** در این قالب پیاده‌سازی نشده‌اند. نقشه راه بک‌اند در `docs/PRODUCT-STRUCTURE.md` آمده است.
- فونت‌های Vazirmatn و Inter از Google Fonts بارگذاری می‌شوند. برای استفاده آفلاین فایل‌ها را در `assets/fonts` قرار دهید و `app.css` را به‌روز کنید. مجوز فونت‌ها را پیش از انتشار تجاری بررسی کنید.

## افزودن صفحه جدید

1. در `assets/js/data/pages.js` یک کلید جدید با `title`، `sub` و `columns` و `rows` تعریف کنید.
2. در `index.html` یک `<a class="nav-link" data-page="...">` به منو اضافه کنید.
3. در `locales/fa.json` و `locales/en.json` عنوان انگلیسی آن را در بخش `nav` بنویسید.

اگر صفحه نیاز به رندر خاص دارد، یک تابع در `assets/js/views/` بسازید و در `renderPage` (فایل `core/router.js`) به آن وصل کنید.
